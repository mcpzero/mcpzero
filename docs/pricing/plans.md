## Plan details

### Free

For solo developers exploring MCP aggregation. One multiplexed tunnel with semantic aggregation and progressive discovery inside a single endpoint. Metadata-only logging and traffic visualization — request and response bodies are never stored.

### Personal

For individuals who need short-term payload history. Two tunnels, aggregation and progressive discovery within each endpoint, and 48-hour cloud storage for request/response payloads. Does not include cross-endpoint aggregation.

### Team

For teams that share MCP capabilities across members. Fifty tunnels, cross-endpoint aggregation and discovery, 30-day cloud storage, searchable audit logs, and team environment sharing. Rate limit of 60 requests per minute per endpoint.

### Enterprise

For organizations with compliance, scale, or deployment requirements. Unlimited tunnels, private cloud storage (S3 / R2 / OSS), Semantic WAF, Tool Hijacking Defense, DLP, private or hybrid-cloud deployment, custom rate limits, and dedicated support with SLA.

## What's included at every tier

- Zero-trust edge authentication with API keys
- Encrypted WebSocket tunnel from local MCP servers to the gateway
- Metadata call ledger (tool name, latency, status)
- Traffic visualization dashboard
