# Quickstart `mcp.json`

Sample MCP server config for the [one-minute setup](https://mcpzero.io/docs/getting-started/overview/#one-minute-setup) guide.

```bash
cp examples/quickstart/mcp.json ./mcp.json
mcpzero tunnel start --endpoint ep_abc123 --mcp-config ./mcp.json
```

Adjust server names, commands, and paths to match your environment.
